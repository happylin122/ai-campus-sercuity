## 这个仓库是什么

本项目完整版是「Vue + FastAPI + MySQL + Redis」的前后端分离服务，靠 Docker Compose 编排。
本仓库是它的**纯前端静态演示版**，用来在没有服务器的环境下展示系统实际运行效果。

为了在没有后端的情况下让功能真实可用，做了两件事：

**1. 规则引擎移植到浏览器**（`demo-rules.js`）

把后端的检测规则逐条搬成 JavaScript，判定结果与后端一致：

- 内容安全 8 类：提示词注入、自伤风险、暴力伤害、违法危险内容、隐私索取、学术诚信、账号与系统入侵、骚扰与网络霸凌；含各自的排除条件（例如「如何防范提示词注入」不会误判）
- 隐私实体 7 类：身份证号、银行卡号、手机号、电子邮箱、学号、姓名、地址；含重叠抑制与两种脱敏样式
- 风险等级映射：`≥80 高危 / ≥50 中危 / >0 低危 / 0 安全`
- 网关决策阈值：`≥80 拦截`、`≥50 转人工复核`，命中隐私实体则脱敏放行

**2. 接口适配层**（`mock-api.js`）

拦截前端的 `/api/*` 请求，在内存中重建后端行为：检测记录写入、按时间/模块/等级筛选与分页、看板统计、审计事件、人工复核状态流转、安全评估批次。数据不离开浏览器。

## 功能

| 模块 | 说明 |
|---|---|
| AI 助手 | 经安全网关的对话，输入输出双向检查；命中拦截策略时给出安全回复 |
| 审计中心 | AI 请求事件与检测记录两类审计，支持筛选、复核、导出 CSV |
| 监测中心 | 拦截率、待复核、依据缺失、P95 延迟等指标与自动告警 |
| 检测器调试 | 单条文本的内容安全检测，展示命中位置与风险分 |
| 隐私文档处理 | 粘贴文本或上传文件识别隐私实体，可导出脱敏后的 .docx |
| 安全评估 | 内置回归用例集，在浏览器内跑真实规则并产出质量门禁结论 |
| 系统管理 | 用户角色、模型 API Key 配置、校园知识库管理、AI 信任矩阵 |

## 与完整版的差异

| | 本演示版 | 完整部署版 |
|---|---|---|
| 内容安全 / 隐私检测 | 一致 | 一致 |
| 数据持久化 | 存浏览器内存，刷新重置 | MySQL 长期保存 |
| AI 对话 | 内置校园知识库应答 | 接入真实大模型 |
| Python 代码沙箱 | 不支持 | 支持 |

完整版部署方式见项目主仓库的 `DEPLOY.md` 与 `deploy/deploy.sh`。

## 本地开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 构建到 dist/
```

技术栈：Vue 3 + Vite + Element Plus，路由使用 hash 模式以适配静态托管。
